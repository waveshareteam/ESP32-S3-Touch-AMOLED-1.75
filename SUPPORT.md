# Support

Use GitHub issues for reproducible software problems in this repository.

When reporting a problem, include:

- Board name and hardware revision if known.
- Example path.
- Framework and version, such as ESP-IDF or Arduino-ESP32.
- Steps to reproduce.
- Expected behavior.
- Actual behavior.
- Logs or screenshots when helpful.

For product support, warranty, order-specific questions, or replacement requests, contact Waveshare support through the official support channels.
