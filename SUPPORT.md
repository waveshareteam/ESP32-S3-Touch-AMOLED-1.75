## Repository Support

Use [GitHub issues](https://github.com/waveshareteam/ESP32-S3-Touch-AMOLED-1.75/issues/new/choose)
for reproducible problems with source examples, repository documentation, CI workflows, or
published firmware artifacts.

When reporting a problem, include:

- Board name and hardware revision if known.
- Example, document, or firmware path.
- Framework and version, such as ESP-IDF or Arduino-ESP32.
- Release asset name or source commit, when applicable.
- Steps to reproduce.
- Expected behavior.
- Actual behavior.
- The smallest relevant serial-log excerpt, backtrace, or screenshot.

GitHub issues are public. Before posting, remove passwords, Wi-Fi credentials, API keys, tokens,
private chat or media content, personal email addresses, device identifiers, private network
addresses, and host-specific paths or usernames. Do not upload complete NVS dumps, SD-card images,
or unrelated logs when a minimal excerpt can reproduce the problem.

Security vulnerabilities must not be reported through a public issue. Follow the
[Security Policy](SECURITY.md) instead.
