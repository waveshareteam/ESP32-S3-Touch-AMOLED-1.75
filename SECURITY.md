# Security Policy

[中文](SECURITY_ZH.md)

Do not report suspected vulnerabilities, leaked credentials, or exploitable details through a
public GitHub issue, discussion, pull request, or log attachment.

Use the official Waveshare [Technical Support](https://docs.waveshare.com/ESP32-S3-Touch-AMOLED-1.75/Technical-Support)
channel to report a vulnerability privately. The corresponding Chinese support page is
[技术支持](https://docs.waveshare.net/ESP32-S3-Touch-AMOLED-1.75/Technical-Support/).

Include only the information needed to investigate:

- Affected product and hardware revision, if known.
- Affected repository path, release asset, and version or source commit.
- Reproduction conditions and a minimal proof of concept.
- Security impact and any suggested mitigation.

Remove unrelated personal information, credentials, private chat or media content, device
identifiers, and host-specific paths from reports and attachments. Never send active passwords,
API keys, tokens, or private keys. If a credential may already be exposed, revoke or rotate it
immediately through the service that issued it.

For non-security defects, use the public
[bug report template](https://github.com/waveshareteam/ESP32-S3-Touch-AMOLED-1.75/issues/new/choose).
