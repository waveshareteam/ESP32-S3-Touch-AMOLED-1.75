## ESP32-S3-Touch-AMOLED-1.75 v1.0.1

[English](v1.0.1.md)

此版本对示例目录结构进行了现代化整理，验证了当前支持的 ESP-IDF 和 Arduino 工具链，并为
每个第一方示例发布由 CI 构建的固件。

### 固件产物

此版本包含 19 个 `*-combined.zip` 固件包：

- 使用 ESP-IDF `v5.5.4` 构建的 5 个 ESP-IDF 示例。
- 使用 ESP-IDF `v6.0.2` 构建的 5 个 ESP-IDF 示例。
- 使用 Arduino-ESP32 `3.3.10` 构建的 9 个 Arduino 示例。

每个软件包都包含一个从偏移地址 `0x0` 烧录的 `*-combined.bin`、原始分区二进制文件、适用于
Shell 和 Windows 的烧录脚本，以及带校验值的 manifest。`manifest-combined-assets.json`
产物包含全部软件包的 SHA256 校验值和源码元数据。

### 主要更新

- 全部 14 个第一方示例均已完成实机验证。
- `04_Immersive_block` 现在会限制显示锁等待时间并减少每帧工作量，以避免看门狗复位。
- `05_Spec_Analyzer` 和发布固件使用正确的 16 MB Flash 配置。
- ESP-IDF 工程可在两个受支持的版本系列上构建。
- Arduino 示例使用当前验证过的 Arduino-ESP32 Core 和仓库内置库构建。
- 仓库设置、示例、固件、CI、发布和故障排查文档现已归档在 `docs/` 下。

### 烧录

解压所需示例的软件包，安装 esptool，然后运行：

```bash
./flash_combined.sh /dev/ttyACM0
```

Windows：

```bat
flash_combined.bat COMx
```

脚本会从 `0x0` 烧录合并镜像。不要混用不同软件包中的二进制文件。如果开发板此前报告
32 MB 镜像头不匹配，请只执行一次 Flash 擦除，然后安装完整的 v1.0.1 合并镜像。

`firmware/` 下的工厂恢复镜像与这些可复现的源码构建相互独立。
