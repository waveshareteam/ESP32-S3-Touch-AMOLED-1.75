# Getting Started

This guide covers release firmware, ESP-IDF source builds, and Arduino source builds for the
ESP32-S3-Touch-AMOLED-1.75.

## Before You Start

You need:

- An ESP32-S3-Touch-AMOLED-1.75 board.
- A USB data cable and a stable USB power source.
- The serial port assigned to the board.
- Python 3 for release firmware flashing.
- ESP-IDF or Arduino tools only when building from source.

Use firmware and settings intended for this exact board. The provided projects and release firmware
use a 16 MB flash layout.

## Flash A Release Package

Release packages are generated by GitHub Actions from the tagged source revision.

1. Open the [Releases page](https://github.com/waveshareteam/ESP32-S3-Touch-AMOLED-1.75/releases).
2. Download a `*-combined.zip` file.
3. Extract the archive.
4. Install esptool:

```bash
python -m pip install esptool
```

5. Flash the combined image.

Linux or macOS:

```bash
./flash_combined.sh /dev/ttyACM0
```

Windows:

```bat
flash_combined.bat COM5
```

The scripts write the combined binary at `0x0`. Change the serial port to match your system. The
same archive also contains split binaries and `flash.sh` / `flash.bat` for offset-based flashing.

If automatic reset cannot enter download mode, hold BOOT, tap RESET, start the flash command, and
release BOOT after the transfer begins.

## Build With ESP-IDF

Supported release branches are ESP-IDF `v5.5.4` and `v6.0.2`. Activate the selected ESP-IDF
environment, then build a project from the repository root:

```bash
idf.py -C examples/esp-idf/02_lvgl_demo_v9 \
  -B build/02_lvgl_demo_v9 \
  set-target esp32s3 build
```

Flash and monitor with the same build directory:

```bash
idf.py -C examples/esp-idf/02_lvgl_demo_v9 \
  -B build/02_lvgl_demo_v9 \
  -p PORT flash monitor
```

Managed dependencies are downloaded by the ESP-IDF component manager during configuration. The
ESP-Brookesia project has an additional `sdkconfig.defaults.v6` overlay for ESP-IDF v6; CI applies
that overlay automatically.

## Build With Arduino

The validated Arduino-ESP32 core is `3.3.10`. Use the ESP32-S3 board target with:

- Flash size: 16 MB.
- Partition scheme: `app3M_fat9M_16MB`.
- Bundled libraries: `examples/arduino/libraries`.

Arduino CLI example:

```bash
arduino-cli core install esp32:esp32@3.3.10

arduino-cli compile \
  --fqbn "esp32:esp32:esp32s3:FlashSize=16M,PartitionScheme=app3M_fat9M_16MB" \
  --libraries examples/arduino/libraries \
  examples/arduino/01_HelloWorld
```

In Arduino IDE, add the `examples/arduino/libraries` folders to the sketchbook libraries or use the
bundled copies as the source of the required versions. Select the same flash size and partition
scheme before uploading.

## Example-Specific Hardware

- `07_LVGL_SD_Test` requires a compatible microSD card.
- `08_ES8311` exercises the audio codec and audio path.
- `09_LC76G_I2C` requires an LC76G module connected over I2C.
- `04_Immersive_block` uses the QMI8658 IMU for motion input.
- `05_Spec_Analyzer` uses the onboard digital microphones.

See [Example Catalog](examples.md) for the full list and [Troubleshooting](troubleshooting.md) for
common flashing and runtime failures.
