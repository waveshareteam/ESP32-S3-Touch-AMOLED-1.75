# Firmware Artifacts

`Firmware/ESP32-S3-Touch-AMOLED-1.75-FactoryOnly.bin` is a released factory flashing and recovery binary. It is not generated by CI and should not be treated as a source build output.

Source-maintained firmware lives under:

- `examples/esp-idf/`
- `examples/arduino/`

CI build outputs are packaged by `releases/package_firmware.py` and uploaded as workflow artifacts. The generated zip contains `manifest.json`, `flash.sh`, `flash.bat`, `flash_args.txt`, and the binaries needed by esptool.

For local release packaging, build the target project first and run the Python script from the repository root. Generated archives are written under `releases/dist/` by default.

Downloaded CI artifacts should be extracted under `releases/downloads/` by `releases/download_artifacts.py`. Generated archives and downloaded artifacts are ignored and should not be committed.
