# Firmware

`Firmware/ESP32-S3-Touch-AMOLED-1.75-FactoryOnly.bin` is a released factory flashing and recovery binary.

This binary is not generated by CI and should not be treated as a source build output. It remains in the repository so users can recover a board to a known factory image.

## Source Builds

Source-maintained examples live under:

- `examples/esp-idf/`
- `examples/arduino/`

CI validates those source examples. The current workflow is compile-validation focused and does not publish source-built firmware archives.

## Future Release Packaging

If this repository needs CI-generated firmware downloads, add release packaging that includes:

- `manifest.json`
- flash arguments derived from ESP-IDF build metadata where available
- POSIX shell and Windows batch flashing helpers
- firmware binaries under a stable `bin/` directory

Generated archives and downloaded artifacts should stay out of source control under ignored output directories such as `release-artifacts/`, `releases/dist/`, or `releases/downloads/`.
